# Referências oficiais

Fonte de verdade da metodologia — qualquer dúvida sobre regra de cálculo ou campo do formulário, conferir aqui antes de alterar `public/app.js`.

- **`manual-monitoramento-inea-2016.pdf`** — Manual de procedimentos para o monitoramento e avaliação de áreas em Restauração Florestal (INEA, 2016). Define o protocolo DAR, os 7 parâmetros, as faixas de classificação e a fórmula do conceito final (seção 4.3.2).
- **`anexo-ii-ficha-dar-quitacao-florestal.pdf`** — Ficha DAR Quitação Florestas (Anexo II). Estrutura oficial que o PDF exportado pelo app espelha (identificação do técnico, identificação do requerente, tabela de parâmetros × pontos, conceito final).
- **`lista-especies-dof-2024-05-08.xlsx`** — lista de espécies (IBAMA, nome científico/popular) usada para gerar `public/especies.json`, consumido pelo autocomplete de espécies no app.
